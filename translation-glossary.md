# Translation glossary · مسرد الترجمة

The Arabic paper follows the English source section by section. Both use the same data, sample and formulas. The glossary records distinctions that affect how a reader interprets the results.

| English | العربية | Meaning preserved in translation |
| --- | --- | --- |
| Military expenditure | الإنفاق العسكري | The resource input measured by the SIPRI series. |
| Military burden | العبء العسكري | Military expenditure as a percentage of GDP. |
| Gross domestic product | الناتج المحلي الإجمالي | The denominator in the source indicator. |
| Country-year observation | مشاهدة لدولة في سنة معيّنة | The unit of the source panel. |
| Balanced panel | بيانات مقطعية زمنية متوازنة | The same countries are observed in every year. |
| Complete-case selection | اختيار السلاسل المكتملة | Here, selecting countries observed in all fifteen years. |
| Available-case mean | المتوسط المحسوب باستخدام القيم المتاحة | Membership can differ between years. |
| Missing observation | مشاهدة مفقودة | Retained as missing in the data. |
| Arithmetic mean | المتوسط الحسابي | Equal-weight sum divided by the number of countries. |
| Cross-country median | الوسيط بين الدول | The middle level in the sorted country distribution. |
| Change in the median | التغيّر في الوسيط | Subtracting the median level in one year from the median level in another. |
| Median of country changes | وسيط التغيّرات داخل الدول | Sorting each country's change and taking the middle change. |
| Percentage point | نقطة مئوية | An absolute difference between percentages. |
| Percentage change | نسبة التغيّر المئوية | A change divided by the initial value, multiplied by one hundred. |
| Leave-one-country-out analysis | تحليل يستبعد كل دولة على حدة | Recalculating the statistic after each single-country omission. |
| Sensitivity check | فحص الحساسية | How a result changes under a stated analytical choice. |
| Confidence interval | فاصل الثقة | A concept distinct from the omission ranges reported here. |
| Fixed membership | عضوية ثابتة | The set of countries stays constant across the comparison. |
| GDP weighting | الترجيح بحسب الناتج المحلي الإجمالي | Gives countries weights proportional to GDP. |
| Endpoint comparison | المقارنة بين نقطتَي البداية والنهاية | A defined comparison between two dates. |
| Time horizon | الأفق الزمني | The interval over which change is calculated. |
| Reproducibility | قابلية إعادة إنتاج النتائج | Regenerating the same outputs from the supplied data and code. |

For example, a rise from 3% to 4% equals one percentage point and a percentage increase of approximately 33.3%. In Arabic, these are «نقطة مئوية واحدة» and «زيادة بنسبة ٣٣٫٣٪» respectively.

Equation symbols remain in Latin to match the English source and the accompanying code. The figures use English labels with Arabic captions in the translated paper. Source statistical definitions are linked in [SOURCES.md](SOURCES.md).
